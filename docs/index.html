Full Setup Guide

Step-by-Step Instructions

From download to your first automated job submission in 3 minutes.

1

Install JobTracker Desktop Application

Download the installer for your operating system above and complete the one-time OS setup:

  • macOS: Open the downloaded .dmg file and drag Job Tracker into your Applications folder.
    Note on Unsigned App: Because JobTracker is free open-source software without an Apple Developer subscription, right-click the app → select Open → click Open. If prompted, go to System Settings → Privacy & Security and click Open Anyway.
  • Windows: Run the .msi installer. If Windows SmartScreen appears, click More info → Run anyway.
2

Activate the Chrome Companion Extension

The desktop app automatically bundles and extracts the ready-to-use extension for you:

  • Launch JobTracker → go to Settings → Browser Extension Companion.
  • Click the "Reveal Extension Folder" button. This instantly opens the unpacked extension directory in macOS Finder or Windows Explorer!
  • In your browser (Chrome, Brave, or Edge), navigate to chrome://extensions.
  • Toggle Developer mode ON in the top right corner.
  • Click Load unpacked and select the revealed extension folder.
3

Pair Extension with JobTracker

Link the browser extension to your local desktop database over loopback:

  • In JobTracker Settings → Browser Extension Companion, click Copy Token.
  • Click the JobTracker icon in your browser toolbar → open Settings & Pairing.
  • Paste your token into the box and click Save & Connect.
  • The badge turns green: ● Connected.
4

Browse & Auto-Detect Job Details

Simply navigate to any job posting in your browser. Supported platforms include:

  • Supported Portals: LinkedIn, Indeed, Greenhouse, Lever, Ashby, Workday, and any site with Schema.org JobPosting metadata.
  • When viewing a job, the extension badge will show a green checkmark ✓.
  • Press your global hotkey (default: Alt+Shift+J or Cmd+Shift+J) from anywhere.
  • JobTracker will pop up immediately with Company, Role, Location, Salary, Portal, and Description prefilled!
  • Select your reusable address/phone preset, attach your resume (optional), and click Save Application.
5

Manage Pipeline & Analyze Insights

Track your search and stay organized throughout interviews and offers:

  • Kanban Pipeline: Drag or update stages (Applied → Screening → Interview → Offer).
  • Duplicate Guard: JobTracker warns you in real time if you've already applied for the same role at the same company.
  • Insights Dashboard: View response rates, active application streaks, offer metrics, and activity heatmaps.
  • Custom Hotkeys: Change your hotkeys anytime under Settings → Global Hotkeys.

Questions & Answers

Frequently Asked Questions

Can I change the global hotkeys?

Yes! In JobTracker, open Settings → Global Hotkeys. Click the hotkey recorder field, press any key combination you want (e.g. Cmd+Shift+J or Ctrl+Space), and click Apply Hotkeys. It updates immediately system-wide.

Do I need to compile the Chrome extension myself?

No! The compiled extension is pre-packaged inside the JobTracker desktop app. Just click "Reveal Extension Folder" in Settings, and load that folder into chrome://extensions.

Will updating the app delete my existing applications?

Never. JobTracker uses transactional, forward-only migrations. Before performing any database migration, it automatically creates a safe snapshot file (jobtracker.backup-before-v2.db) in your data folder.

Does JobTracker send data to the internet?

No. JobTracker has no backend servers. All data stays in your local SQLite database on your computer.
