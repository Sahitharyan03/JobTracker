# JobTracker Capture Companion Chrome Extension

A lightweight, local-first Manifest V3 Chrome extension that detects job postings as you browse (LinkedIn, Indeed, Greenhouse, Lever, Ashby, Workday, and standard job boards) and securely transfers them to the JobTracker desktop application.

## Features

- **Layered Extraction Engine**:
  1. High-fidelity Schema.org JSON-LD `JobPosting` extractor
  2. Platform-specific extractors for Greenhouse, Lever, Ashby, Workday, LinkedIn, and Indeed
  3. OpenGraph / Twitter Card meta-tag fallback
  4. Heuristic semantic DOM fallback
- **Extracted Fields**:
  - Company name
  - Role / Title
  - Location
  - Work Type (Remote, Hybrid, In-Person, Unknown)
  - Salary Range
  - Job ID
  - Posting URL
  - Full Job Description
  - Employment Type (Full-time, Contract, Internship, etc.)
  - Detection Source & Confidence
- **Zero-Cloud & 100% Local**:
  - Communicates directly with the desktop app over local loopback (`http://127.0.0.1:41724/api/capture`).
  - No external servers, no tracking, no telemetry.
  - Authenticated via secure local bearer token generated by JobTracker.

## How to Install in Chrome / Brave / Edge

1. In the `JobTracker` repository root, run:
   ```bash
   npm run build:extension
   ```
2. Open Chrome (or any Chromium browser) and navigate to `chrome://extensions`.
3. Enable **Developer mode** using the toggle in the top-right corner.
4. Click **Load unpacked**.
5. Select the `browser-extension/dist` folder in this repository.
6. The extension icon will appear in your browser toolbar!

## How to Pair with JobTracker Desktop

1. Open JobTracker on your computer.
2. Go to **Settings** -> **Browser Extension Companion**.
3. Copy the **Security Token** shown in the settings card.
4. Click the JobTracker extension icon in Chrome -> open **Settings & Pairing**.
5. Paste the token and click **Save & Connect**.
6. The status pill will turn green: **Connected (127.0.0.1:41724)**.
7. Now when browsing any job posting, JobTracker will automatically capture the job details and prefill the quick popup when you press the global shortcut (`Cmd+Shift+J` or `Ctrl+Shift+J`)!
